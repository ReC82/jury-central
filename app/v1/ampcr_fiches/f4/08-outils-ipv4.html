4 A. Calculs IPv4 / CIDR pas à pas (tous vérifiés)

La méthode en 5 gestes (à écrire sur la copie)

  1. Préfixe ↔ masque : /n = n bits à 1. Octets possibles du masque : 128 (/25), 192 (/26), 224 (/27), 240 (/28), 248 (/29), 252 (/30), 254, 255. Ex. /20 = 255.255.240.0 (8 + 8 + 4 bits).
  2. Octet significatif = le premier octet du masque différent de 255. Taille du bloc = 256 − cet octet.
  3. Adresse réseau : dans l'octet significatif, le multiple du bloc juste inférieur ou égal à l'octet de l'adresse ; octets suivants à 0.
  4. Diffusion (broadcast) = réseau + bloc − 1 dans l'octet significatif, octets suivants à 255.
  5. Plage d'hôtes = réseau + 1 → diffusion − 1. Nombre d'hôtes = 2(32 − n) − 2.

Exemple 1 détaillé : 192.168.40.77/26

  1. /26 → masque 255.255.255.192 (26 = 8 + 8 + 8 + 2 bits ; 11000000 = 128 + 64 = 192).
  2. Octet significatif : le 4e (192) ; bloc = 256 − 192 = 64 → réseaux .0, .64, .128, .192.
  3. 77 est entre 64 et 127 → réseau 192.168.40.64.
  4. Diffusion = 64 + 64 − 1 = 127 → 192.168.40.127.
  5. Hôtes : 192.168.40.65 à 192.168.40.126, soit 26 − 2 = 62.

Vérification binaire (ET logique) sur le 4e octet : 77 = 0100 1101 ; 192 = 1100 0000 ; 0100 1101 ET 1100 0000 = 0100 0000 = 64 ✔.

Exemple 2 détaillé (bloc dans le 3e octet) : 172.16.45.200/20

  1. /20 → 255.255.240.0 (3e octet : 4 bits à 1 = 11110000 = 240).
  2. Octet significatif : 3e ; bloc = 256 − 240 = 16 → 0, 16, 32, 48…
  3. 45 est entre 32 et 47 → réseau 172.16.32.0 (4e octet à 0).
  4. Diffusion : 32 + 16 − 1 = 47, 4e octet à 255 → 172.16.47.255.
  5. Hôtes : 172.16.32.1 à 172.16.47.254 ; 212 − 2 = 4 094.

Binaire : 45 = 0010 1101 ; 240 = 1111 0000 ; ET = 0010 0000 = 32 ✔.
