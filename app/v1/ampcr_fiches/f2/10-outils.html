4. Outils et commandes : syntaxe exacte, sortie, interprétation, suite

Règle d'examen : pour chaque commande, écris pourquoi tu la lances, ce que tu attends, ce que signifie un résultat anormal et ce que tu fais ensuite. Classe-la : lecture (sans risque) ou modification (précaution). Commandes réseau (ipconfig, ping, tracert, nslookup, ip) : → Fiche 4 · Ordre des tests. SMART, test mémoire : → Fiche 1.

4.5 Lire une sortie : trois exemples commentés

C:\> bcdedit /enum
Gestionnaire de démarrage Windows
---------------------------------
identificateur          {bootmgr}
device                  partition=\Device\HarddiskVolume1
path                    \EFI\Microsoft\Boot\bootmgfw.efi
default                 {current}
timeout                 30

Chargeur de démarrage Windows
-----------------------------
identificateur          {current}
device                  partition=C:
path                    \Windows\system32\winload.efi
osdevice                partition=C:
systemroot              \Windows
bootmenupolicy          Standard

Lecture : path … .efi = démarrage UEFI (winload.exe = hérité) ; device partition=C: cohérent. Si device unknown → BCD à recréer (P1.2). safeboot Minimal présent → PC bloqué en mode sans échec (retirer la valeur).

$ systemctl status cups
○ cups.service - CUPS Scheduler
     Loaded: loaded (/lib/systemd/system/cups.service; disabled; preset: enabled)
     Active: inactive (dead)

Lecture : disabled = ne démarre pas au boot ; inactive (dead) = arrêté, sans erreur. Ce n'est pas une panne du service mais une configuration : sudo systemctl enable --now cups, puis revérifier active (running) et imprimer une page de test.

$ df -h ; df -i /
Sys. de fichiers Taille Utilisé Dispo Uti% Monté sur
/dev/sda2           98G     61G   32G  66% /
Sys. de fichiers  Inœuds   IUtil.  ILibre IUti% Monté sur
/dev/sda2       6553600  6553600       0  100% /

Lecture : il reste 32 Go mais 0 inode : « No space left on device » vient d'un excès de petits fichiers. sudo du --inodes -xd1 / | sort -n | tail pour trouver le dossier, puis purge ciblée après accord.
