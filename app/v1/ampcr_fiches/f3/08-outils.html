8.2 Commandes pour prouver l'état du lien physique

PS C:\> Get-NetAdapter | Format-Table Name,InterfaceDescription,Status,LinkSpeed
Name     InterfaceDescription           Status  LinkSpeed
----     --------------------           ------  ---------
Ethernet Intel(R) Ethernet Connection   Up      100 Mbps

Interprétation : Up 1 Gbps attendu ; Up 100 Mbps → P4.2 ; Disconnected → P4.1 ; Disabled → carte désactivée (réactiver : Enable-NetAdapter -Name "Ethernet", ou ncpa.cpl).

PS C:\> Get-NetAdapterAdvancedProperty -Name "Ethernet" -DisplayName "*Duplex*"
Name      DisplayName          DisplayValue
----      -----------          ------------
Ethernet  Speed & Duplex       100 Mbps Full Duplex

Interprétation : valeur forcée → remettre « Auto Negotiation » / « Négociation automatique » (nom exact selon le pilote) ; vérifier le port du switch.

$ sudo ethtool enp3s0
	Supported link modes:   10baseT/Full 100baseT/Full 1000baseT/Full
	Speed: 1000Mb/s
	Duplex: Full
	Auto-negotiation: on
	Link detected: yes
$ ip -s link show enp3s0

Lire state UP/DOWN, NO-CARRIER (pas de lien), compteurs errors qui montent entre deux relevés (erreurs physiques ou duplex).

Côté switch administrable : état et vitesse du port, compteurs CRC/FCS, collisions tardives (signe d'un désaccord de duplex), état PoE, informations DDM des modules optiques (températures, Tx, Rx en dBm).
