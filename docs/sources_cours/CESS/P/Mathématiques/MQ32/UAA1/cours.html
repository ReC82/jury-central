MQ32 UAA1 – Approche graphique d’une fonction
Cours complet imprimable – Jury CESS

Objectif de l’UAA : rechercher des informations sur une fonction à partir de sa représentation graphique.
Important : dans cette UAA, on travaille uniquement à partir du graphique. On ne doit pas étudier les fonctions par des calculs techniques ou par une expression analytique, sauf lecture directe d’un graphique ou comparaison graphique.
À l’examen : il faut savoir lire un graphique, utiliser le vocabulaire exact, justifier avec des phrases en contexte, et comparer deux graphiques quand la situation le demande.

2. Les bases : repère, axes et coordonnées

2.1 Le repère cartésien

Un graphique se lit dans un repère composé de deux axes :
  • l’axe horizontal : axe des abscisses, noté souvent x ou Ox ;
  • l’axe vertical : axe des ordonnées, noté souvent y ou Oy.
Un point se note (x ; y). La première coordonnée se lit horizontalement, la deuxième verticalement.

2.2 Lire un point

Pour lire un point sur un graphique :
  1. Repère sa position horizontale : c’est la valeur de x.
  2. Repère sa position verticale : c’est la valeur de y.
  3. Écris le point sous la forme (x ; y).
Piège fréquent : inverser x et y. Dans (3 ; 5), 3 est l’abscisse et 5 est l’ordonnée.

3. Qu’est-ce qu’une fonction ?

Une fonction est une règle qui associe à chaque valeur de x au maximum une seule valeur de y.
On note souvent : y = f(x)
Cela se lit : “y est l’image de x par la fonction f”.

3.1 Variable indépendante et variable dépendante

MotExplicationExemple
xVariable indépendante : celle que l’on choisit ou observe.Masse de macarons vendus.
f(x)Variable dépendante : elle dépend de x.Frais ou chiffre d’affaires.

3.2 Reconnaître si un graphique représente une fonction

Un graphique représente une fonction si une droite verticale ne coupe jamais le graphique en plus d’un point.

4. Image et antécédent

4.1 Image

L’image d’un nombre x est la valeur de y correspondante sur le graphique.
Si le point (3 ; 7) est sur le graphique de f, alors f(3) = 7.
On dit : “l’image de 3 par f est 7”.

4.2 Antécédent

Un antécédent d’un nombre y est une valeur de x qui donne cette valeur y.
Si f(3) = 7, alors 3 est un antécédent de 7.
Piège fréquent : l’image est une valeur de y. L’antécédent est une valeur de x. Un même nombre peut avoir plusieurs antécédents.

Exemple corrigé 1

Sur un graphique, on lit les points suivants : (0 ; 2), (2 ; 5), (4 ; 5), (6 ; 1).
1) Quelle est l’image de 2 ?
2) Quels sont les antécédents de 5 ?
3) Quelle est l’image de 6 ?
1) Le point (2 ; 5) signifie que f(2)=5. L’image de 2 est 5.
2) On cherche les x pour lesquels y = 5. Les points concernés sont (2 ; 5) et (4 ; 5). Les antécédents de 5 sont 2 et 4.
3) Le point (6 ; 1) signifie que f(6)=1. L’image de 6 est 1.

5. Domaine et ensemble-image

5.1 Domaine

Le domaine d’une fonction est l’ensemble des valeurs de x pour lesquelles le graphique existe.

5.2 Ensemble-image

L’ensemble-image est l’ensemble des valeurs de y prises par la fonction.

5.3 Intervalles

NotationSignification
[a ; b]a et b sont compris.
]a ; b[a et b ne sont pas compris.
[a ; b[a compris, b non compris.
]a ; b]a non compris, b compris.
[a ; +∞[de a compris vers l’infini.

Exemple corrigé 2

Un graphique commence au point fermé (-2 ; 1), monte jusqu’à (3 ; 6), puis descend jusqu’au point fermé (7 ; -1).
Donne le domaine et l’ensemble-image.
Le graphique existe pour les x allant de -2 à 7. Les extrémités sont incluses, car les points sont fermés.
Domaine : [-2 ; 7].
Les valeurs de y vont de -1 à 6. Ces valeurs sont atteintes.
Ensemble-image : [-1 ; 6].

6. Zéros et intersections avec les axes

6.1 Zéro d’une fonction

Un zéro de la fonction est une valeur de x pour laquelle f(x)=0.
Graphiquement, les zéros sont les abscisses des points où le graphique coupe ou touche l’axe des x.

6.2 Intersection avec les axes

IntersectionCe qu’on cherche
Avec l’axe des xLes points où y = 0. Ce sont les zéros de la fonction.
Avec l’axe des yLe point où x = 0. On lit f(0).
Piège fréquent : le zéro est une valeur de x, pas un point complet. Le point d’intersection avec l’axe des x est par exemple (4 ; 0), mais le zéro est 4.

Exemple corrigé 3

Un graphique coupe l’axe des x aux points (-1 ; 0), (2 ; 0) et (5 ; 0). Il coupe l’axe des y au point (0 ; -3).
1) Quels sont les zéros ?
2) Quelle est l’image de 0 ?
1) Les zéros sont les abscisses des points où y = 0 : -1, 2 et 5.
2) Le point sur l’axe des y est (0 ; -3), donc f(0) = -3.

7. Signe d’une fonction

Étudier le signe d’une fonction, c’est dire où elle est :
  • positive : graphique au-dessus de l’axe des x ;
  • nulle : graphique sur l’axe des x ;
  • négative : graphique en-dessous de l’axe des x.

Méthode : tableau de signes

1. Repère les zéros de la fonction.
2. Coupe le domaine en intervalles grâce à ces zéros.
3. Regarde si le graphique est au-dessus ou en-dessous de l’axe des x sur chaque intervalle.
4. Écris +, 0 ou −.

Exemple corrigé 4

Une fonction a pour domaine [-4 ; 6]. Elle coupe l’axe des x en -1 et 3. Elle est au-dessus de l’axe entre -4 et -1, en-dessous entre -1 et 3, puis au-dessus entre 3 et 6. Donne son signe.
La fonction est positive sur [-4 ; -1[ et ]3 ; 6].
Elle est nulle pour x = -1 et x = 3.
Elle est négative sur ]-1 ; 3[.

8. Croissance et décroissance

Une fonction est :
  • croissante quand le graphique monte lorsqu’on va de gauche à droite ;
  • décroissante quand le graphique descend lorsqu’on va de gauche à droite ;
  • constante quand le graphique reste horizontal.

Méthode : tableau de variation

1. Lis le graphique de gauche à droite.
2. Repère les endroits où le sens change : sommet, creux, point de retournement.
3. Note les intervalles où la fonction monte ou descend.
4. Indique les valeurs importantes dans un tableau de variation.

Exemple corrigé 5

Une fonction est définie sur [0 ; 10]. Elle monte de x=0 à x=4, descend de x=4 à x=8, puis remonte de x=8 à x=10. Donne ses intervalles de croissance et décroissance.
La fonction est croissante sur [0 ; 4] et sur [8 ; 10].
Elle est décroissante sur [4 ; 8].

9. Maximum et minimum

Le maximum est la plus grande valeur atteinte par la fonction.
Le minimum est la plus petite valeur atteinte par la fonction.

Exemple corrigé 6

Sur un graphique, le point le plus haut est (4 ; 12) et le point le plus bas est (-2 ; -3). Que peut-on dire ?
Le maximum de la fonction est 12. Il est atteint pour x = 4.
Le minimum de la fonction est -3. Il est atteint pour x = -2.
Piège fréquent : ne pas confondre la valeur du maximum avec l’endroit où il est atteint. Dans (4 ; 12), le maximum est 12, et il est atteint en x=4.

10. Comparaison de deux graphiques

Comparer deux fonctions f et g à partir de leurs graphiques, c’est déterminer :
  • où f(x)=g(x) : les graphiques se coupent ;
  • où f(x)>g(x) : le graphique de f est au-dessus de celui de g ;
  • où f(x) : le graphique de f est en-dessous de celui de g.

Exemple corrigé 7 : chiffre d’affaires et frais

Une fonction C(x) représente le chiffre d’affaires et F(x) les frais de production. Sur le graphique, les deux courbes se coupent pour x = 2 kg. Pour x > 2, C(x) est au-dessus de F(x). Interprète.
L’égalité C(x)=F(x) pour x = 2 signifie que le chiffre d’affaires est égal aux frais : il n’y a ni bénéfice ni perte.
Pour x > 2, C(x)>F(x), donc le chiffre d’affaires dépasse les frais : l’activité est rentable.
Pour x < 2, si C(x) est en-dessous de F(x), l’activité est en perte.

11. Répondre en contexte

Pour une question contextualisée :
  1. Identifie ce que représentent x et y.
  2. Lis le graphique avec les unités.
  3. Réponds à la question mathématique.
  4. Traduis le résultat dans la situation réelle.

Exemple corrigé 8

Un graphique donne la température T(t) d’un four en fonction du temps t en minutes. Le maximum est 220 °C atteint à t = 18 min. Interprète.
Mathématiquement, le maximum de la fonction est 220, atteint pour x = 18.
Dans la situation, cela signifie que le four atteint sa température maximale de 220 °C après 18 minutes.

12. Exercices progressifs

A. Exercices “connaître”

1. Explique avec tes mots : image, antécédent, domaine, ensemble-image.

2. Si le point (5 ; 12) appartient au graphique de f, complète : f(5)=… ; 5 est un … de 12 ; 12 est l’… de 5.

3. Quelle différence y a-t-il entre un zéro de fonction et une intersection avec l’axe des x ?

B. Exercices “appliquer”

4. Une fonction passe par les points (0 ; 3), (2 ; 7), (4 ; 1), (6 ; 1).
a) Quelle est l’image de 2 ?
b) Quels sont les antécédents de 1 ?
c) Quelle est l’image de 0 ?

5. Une fonction définie sur [-3 ; 5] coupe l’axe des x en -2 et 4. Elle est positive sur [-3 ; -2[, négative sur ]-2 ; 4[, positive sur ]4 ; 5]. Fais une phrase complète décrivant son signe.

6. Une fonction monte sur [0 ; 3], descend sur [3 ; 7], puis reste constante sur [7 ; 10]. Donne ses intervalles de croissance, décroissance et constance.

C. Exercices “transférer”

7. Un graphique représente la quantité d’eau dans un réservoir en fonction du temps. La fonction est décroissante de 0 à 8 h, puis constante de 8 h à 12 h. Interprète dans la situation.

8. Deux forfaits téléphoniques sont représentés par deux graphiques A(x) et B(x), où x est le nombre de Go utilisés et y le prix en euros. Les graphiques se coupent pour x = 12. Pour x < 12, A est en-dessous de B ; pour x > 12, A est au-dessus de B. Quel forfait choisir selon la consommation ? Justifie.

9. Une fonction bénéfice B(x) est positive à partir de x = 15. Que signifie cette information pour une entreprise ?

13. Corrections détaillées des exercices

1. Image : valeur de y correspondant à une valeur de x. Antécédent : valeur de x qui donne une valeur de y. Domaine : ensemble des x où la fonction existe. Ensemble-image : ensemble des valeurs de y prises par la fonction.
2. Si (5 ; 12) appartient au graphique, alors f(5)=12. 5 est un antécédent de 12. 12 est l’image de 5.
3. Un zéro est une valeur de x telle que f(x)=0. L’intersection avec l’axe des x est le point complet correspondant, par exemple (2 ; 0). Le zéro est 2.
4. a) L’image de 2 est 7, car le point (2 ; 7) est donné.
b) Les antécédents de 1 sont 4 et 6, car les points (4 ; 1) et (6 ; 1) sont donnés.
c) L’image de 0 est 3.
5. La fonction est positive sur [-3 ; -2[ et ]4 ; 5], nulle pour x=-2 et x=4, négative sur ]-2 ; 4[.
6. La fonction est croissante sur [0 ; 3], décroissante sur [3 ; 7] et constante sur [7 ; 10].
7. De 0 à 8 h, la quantité d’eau diminue : le réservoir se vide. De 8 h à 12 h, la quantité reste constante : il n’y a plus de variation, donc le niveau d’eau ne change pas.
8. Pour x < 12, A est moins cher car son graphique est en-dessous de B. Pour x = 12, les deux forfaits coûtent le même prix. Pour x > 12, B devient moins cher car A passe au-dessus de B.
9. Si le bénéfice est positif à partir de x = 15, cela signifie que l’entreprise commence à gagner de l’argent à partir de 15 unités vendues, produites ou utilisées selon le contexte.

14. Mini-test final type examen

Consigne : justifie chaque réponse par une phrase. Les réponses doivent être données à partir du graphique ou des informations graphiques, pas par une étude algébrique.
Question 1 – Lecture de base
Le graphique d’une fonction f passe par les points suivants :
(-3 ; 2), (-1 ; 0), (0 ; -2), (2 ; 0), (4 ; 5), (6 ; 3).
1) Donne l’image de 4.
2) Donne les antécédents de 0.
3) Donne les zéros de la fonction.
4) Donne f(0).
Question 2 – Domaine et ensemble-image
Une fonction est représentée par une courbe qui commence au point fermé (-4 ; -2), atteint un sommet en (1 ; 6), puis se termine au point fermé (5 ; 0).
1) Donne le domaine.
2) Donne l’ensemble-image.
3) Donne le maximum et indique où il est atteint.
Question 3 – Signe
Une fonction définie sur [-5 ; 7] coupe l’axe des x en -2, 1 et 6. Elle est au-dessus de l’axe sur [-5 ; -2[ et ]1 ; 6[, et en-dessous sur ]-2 ; 1[ et ]6 ; 7].
Décris son signe.
Question 4 – Variations
Une fonction descend sur [-3 ; 0], monte sur [0 ; 4], puis descend sur [4 ; 8].
1) Donne les intervalles de croissance et décroissance.
2) Si f(0)=-5 et f(4)=10, que représentent ces deux valeurs ?
Question 5 – Comparaison de graphiques
Deux fonctions C(x) et F(x) représentent le chiffre d’affaires et les frais d’une vente. Les graphiques se coupent pour x = 8. Pour x < 8, C(x) est en-dessous de F(x). Pour x > 8, C(x) est au-dessus de F(x).
1) Résous graphiquement C(x)=F(x).
2) Résous graphiquement C(x)>F(x).
3) Interprète dans le contexte.

15. Correction du mini-test final

Question 1
1) L’image de 4 est 5, car le point (4 ; 5) est sur le graphique.
2) Les antécédents de 0 sont -1 et 2, car les points (-1 ; 0) et (2 ; 0) sont sur le graphique.
3) Les zéros sont -1 et 2.
4) f(0) = -2.
Question 2
1) Le graphique existe de x=-4 à x=5, donc le domaine est [-4 ; 5].
2) Les valeurs de y vont de -2 à 6, donc l’ensemble-image est [-2 ; 6].
3) Le maximum est 6, atteint pour x=1.
Question 3
La fonction est positive sur [-5 ; -2[ et ]1 ; 6[.
Elle est nulle pour x=-2, x=1 et x=6.
Elle est négative sur ]-2 ; 1[ et ]6 ; 7].
Question 4
1) La fonction est décroissante sur [-3 ; 0], croissante sur [0 ; 4], puis décroissante sur [4 ; 8].
2) f(0)=-5 est une valeur minimale locale : la fonction cesse de descendre et commence à monter. f(4)=10 est une valeur maximale locale : la fonction cesse de monter et commence à descendre.
Question 5
1) Graphiquement, C(x)=F(x) pour x=8.
2) Graphiquement, C(x)>F(x) pour x>8.
3) Pour 8 unités vendues, le chiffre d’affaires est égal aux frais : il n’y a ni bénéfice ni perte. Pour plus de 8 unités, le chiffre d’affaires dépasse les frais : l’activité devient rentable.

16. Fiche mémo finale

Vocabulaire essentiel

  • Fonction : correspondance qui associe à chaque x au maximum une valeur y.
  • f(x) : image de x par la fonction f.
  • Image : valeur de y correspondant à x.
  • Antécédent : valeur de x qui donne une image donnée.
  • Domaine : ensemble des valeurs de x où le graphique existe.
  • Ensemble-image : ensemble des valeurs de y prises par la fonction.
  • Zéro : valeur de x telle que f(x)=0.
  • Maximum : plus grande valeur de la fonction.
  • Minimum : plus petite valeur de la fonction.

Procédures

Ce qu’on chercheComment faire sur le graphique
Image de aPartir de x=a, monter/descendre jusqu’au graphique, lire y.
Antécédent de bPartir de y=b, aller jusqu’au graphique, lire les x possibles.
DomaineRegarder de quel x à quel x le graphique existe.
Ensemble-imageRegarder de quel y à quel y le graphique monte/descend.
ZérosLire les abscisses des intersections avec l’axe des x.
SigneAu-dessus de l’axe x : positif ; sur l’axe : nul ; en-dessous : négatif.
CroissanceLe graphique monte de gauche à droite.
DécroissanceLe graphique descend de gauche à droite.
Comparer f et gf>g si f est au-dessus de g ; f<g si f est en-dessous ; f=g aux intersections.

Pièges fréquents

  • Confondre image et antécédent.
  • Confondre zéro et ordonnée à l’origine.
  • Dire “maximum = x” au lieu de donner la valeur de y.
  • Oublier les unités du graphique.
  • Ne pas interpréter le résultat dans le contexte.
  • Lire trop vite une échelle irrégulière ou mal graduée.
