MQ34 UAA2 – Statistique à deux variables
Cours complet imprimable – Jury CESS

Objectif : apprendre à analyser deux variables numériques ensemble : construire un nuage de points, reconnaître une tendance, tracer une droite d’ajustement, utiliser la droite de Mayer ou la droite des moindres carrés, et interpréter correctement la corrélation sans la confondre avec une causalité.
Compétence centrale : représenter des données, ajuster un modèle linéaire quand c’est pertinent, estimer une valeur, puis critiquer la portée de l’estimation.

1. Qu’est-ce qu’une statistique à deux variables ?

On parle de statistique à deux variables lorsqu’on mesure deux grandeurs pour chaque individu. Chaque donnée devient un couple (x ; y).

2. Nuage de points

Un nuage de points est un graphique où chaque couple (x ; y) est placé dans un repère. Il sert à voir rapidement s’il existe une tendance.
Méthode :
1. Lire les couples de données.
2. Choisir une échelle adaptée.
3. Nommer les axes et les unités.
4. Placer tous les points.
5. Observer la forme générale : tendance positive, négative, forte, faible, linéaire ou non linéaire.

3. Lire une tendance

Aspect du nuageNomInterprétation
Les points montent de gauche à droite.Corrélation positiveQuand x augmente, y tend à augmenter.
Les points descendent de gauche à droite.Corrélation négativeQuand x augmente, y tend à diminuer.
Les points sont proches d’une droite.Tendance linéaire forteUne droite d’ajustement peut être pertinente.
Les points sont très dispersés.Tendance faible ou absenteUne droite peut être peu fiable.
Piège : ne trace pas une droite d’ajustement simplement parce qu’on te le demande. Il faut d’abord vérifier que le nuage ressemble globalement à une droite.

4. Ajustement linéaire

Un ajustement linéaire consiste à résumer un nuage de points par une droite. La droite ne passe pas par tous les points : elle représente seulement une tendance moyenne.

Interpolation et extrapolation

MotDéfinitionFiabilité
InterpolationPrévoir une valeur dans la zone des données observées.Plus fiable.
ExtrapolationPrévoir une valeur hors de la zone des données observées.Plus risquée.

5. Droite de Mayer

La droite de Mayer est une droite d’ajustement construite à partir de deux points moyens.
Procédure Mayer :
1. Trier les points selon les x croissants.
2. Partager les points en deux groupes de même taille ou presque.
3. Calculer le point moyen du premier groupe : G₁(x̄₁ ; ȳ₁).
4. Calculer le point moyen du second groupe : G₂(x̄₂ ; ȳ₂).
5. Tracer la droite passant par G₁ et G₂.

Exemple corrigé

On donne les points : (1 ; 8), (2 ; 9), (3 ; 11), (4 ; 12), (5 ; 14), (6 ; 15), (7 ; 17), (8 ; 18). Calcule les deux points moyens de Mayer.
Groupe 1 : (1 ; 8), (2 ; 9), (3 ; 11), (4 ; 12).
x̄₁=(1+2+3+4)/4=2,5 et ȳ₁=(8+9+11+12)/4=10.
Donc G₁=(2,5 ; 10).

Groupe 2 : (5 ; 14), (6 ; 15), (7 ; 17), (8 ; 18).
x̄₂=(5+6+7+8)/4=6,5 et ȳ₂=(14+15+17+18)/4=16.
Donc G₂=(6,5 ; 16).

6. Équation d’une droite d’ajustement

Une droite s’écrit souvent y = ax + b, où a est la pente et b l’ordonnée à l’origine.
Avec deux points (x₁ ; y₁) et (x₂ ; y₂) :
a = (y₂ − y₁) / (x₂ − x₁)

Exemple corrigé

La droite de Mayer passe par G₁(2,5 ; 10) et G₂(6,5 ; 16). Trouve une équation.
Pente : a=(16−10)/(6,5−2,5)=6/4=1,5.
Donc y=1,5x+b.
Avec (2,5 ; 10) : 10=1,5×2,5+b, donc b=6,25.
Équation : y=1,5x+6,25.

7. Droite des moindres carrés

La droite des moindres carrés est une droite calculée pour minimiser globalement les écarts entre les points et la droite. Elle est généralement obtenue avec une calculatrice ou un tableur.
MéthodeAvantageLimite
Droite de MayerSimple, faisable à la main.Dépend du découpage des points.
Moindres carrésUtilise tous les points de manière systématique.Souvent calculée par outil ; ne garantit pas que le modèle soit pertinent.

8. Corrélation et causalité

La corrélation mesure le lien statistique entre deux variables. Elle peut être positive, négative, forte ou faible.
Règle essentielle : corrélation ne signifie pas causalité. Deux variables peuvent évoluer ensemble à cause d’un troisième facteur caché.

Exemple

On observe que les ventes de glaces et les coups de soleil augmentent en même temps. Les glaces causent-elles les coups de soleil ?
Non. Une variable cachée probable est la météo. Quand il fait chaud et ensoleillé, les gens achètent plus de glaces et ont plus de coups de soleil. Il y a corrélation, mais pas causalité directe.

10. Corrections détaillées

1. Nuage de points : graphique de couples (x ; y). Ajustement linéaire : droite qui résume une tendance. Interpolation : estimation dans la zone observée. Extrapolation : estimation hors de la zone observée.
2. Mayer utilise deux points moyens calculés à partir de deux groupes. Les moindres carrés utilisent tous les points et minimisent les écarts.
3. Une corrélation montre un lien statistique, mais ne prouve pas qu’une variable provoque l’autre. Il peut y avoir une cause cachée.
4. Groupe 1 : (1 ; 3), (2 ; 5), (3 ; 6). G₁=(2 ; 14/3)≈(2 ; 4,67).
Groupe 2 : (4 ; 8), (5 ; 10), (6 ; 11). G₂=(5 ; 29/3)≈(5 ; 9,67).
5. y=2,4×12+5=33,8.
6. a=(21−9)/(8−2)=12/6=2.
7. C’est une extrapolation très éloignée. La prévision est peu fiable et doit être interprétée avec prudence.
8. Non. Les élèves motivés peuvent réviser plus et réussir mieux. Il faut une étude plus contrôlée pour parler de causalité.

Question 1. Un nuage de points monte globalement de gauche à droite et les points sont proches d’une droite.
1) Quelle tendance observe-t-on ?
2) Un ajustement linéaire est-il pertinent ?
3) Peut-on conclure à une causalité ?
Question 2. Points : (1 ; 6), (2 ; 7), (3 ; 9), (4 ; 11), (5 ; 13), (6 ; 14), (7 ; 16), (8 ; 18).
Calcule les deux points moyens de Mayer.
Question 3. Une droite passe par G₁(2,5 ; 8,25) et G₂(6,5 ; 15,25).
1) Calcule la pente.
2) Trouve une équation.
3) Estime y pour x=10.
Question 4. Un modèle est construit avec x entre 5 et 30. Estimer y pour x=18 est-il une interpolation ou une extrapolation ? Et pour x=80 ? Laquelle est la plus fiable ?
Question 5. On observe une forte corrélation positive entre ventes de cafés et ventes de parapluies. Explique pourquoi cela ne prouve pas que les cafés causent l’achat de parapluies.

12. Correction du mini-test

Q1. Tendance positive. Oui, l’ajustement linéaire est pertinent car les points sont proches d’une droite. Non, une corrélation ne prouve pas une causalité.
Q2. Groupe 1 : G₁=(2,5 ; 8,25). Groupe 2 : G₂=(6,5 ; 15,25).
Q3. Pente : a=(15,25−8,25)/(6,5−2,5)=7/4=1,75.
Équation : y=1,75x+3,875.
Pour x=10 : y=21,375.
Q4. x=18 : interpolation. x=80 : extrapolation. L’interpolation est plus fiable car elle reste dans la zone observée.
Q5. Une variable cachée, comme la pluie ou la météo, peut expliquer les deux ventes. Il y a corrélation, mais pas causalité démontrée.

13. Fiche mémo finale

Définitions

  • Nuage de points : graphique de couples (x ; y).
  • Ajustement linéaire : droite qui résume une tendance.
  • Droite de Mayer : droite passant par deux points moyens.
  • Moindres carrés : droite calculée en minimisant les écarts aux points.
  • Interpolation : estimation dans la zone observée.
  • Extrapolation : estimation hors de la zone observée.
  • Corrélation : lien statistique entre deux variables.

Formules

  • x̄ = moyenne des x
  • ȳ = moyenne des y
  • a=(y₂−y₁)/(x₂−x₁)
  • y=ax+b

Pièges fréquents

  • Tracer une droite alors que le nuage n’est pas linéaire.
  • Confondre interpolation et extrapolation.
  • Faire une prévision trop loin des données.
  • Confondre corrélation et causalité.
  • Oublier les unités et le contexte.
