MQ34 UAA13 – Géométrie vectorielle
Cours complet imprimable – Jury CESS

Objectif : utiliser l’outil vectoriel dans une application pratique. Cette UAA travaille la géométrie vectorielle dans le plan : vecteurs, coordonnées, norme, opérations, translations, alignement, parallélisme, rotations d’un quart de tour autour de l’origine et résolution de problèmes géométriques.
À l’examen : il faut reconnaître des vecteurs égaux ou colinéaires, calculer des coordonnées de vecteurs, additionner des vecteurs, multiplier un vecteur par un réel, utiliser une translation ou une rotation, et justifier un alignement ou un parallélisme avec des coordonnées.
Limite de l’UAA : le document indique que l’étude se limite au plan. Les droites du plan peuvent être abordées via vecteurs directeurs, alignement et parallélisme. Les plans de l’espace ne sont pas développés dans ce cours.

1. Repartir des bases : point, repère, coordonnées

Dans un repère du plan, un point est repéré par deux coordonnées : A(x_A ; y_A).
NotationSignification
A(2 ; 5)Point A d’abscisse 2 et d’ordonnée 5.
x_AAbscisse du point A.
y_AOrdonnée du point A.
O(0 ; 0)Origine du repère.

2. Qu’est-ce qu’un vecteur ?

Un vecteur représente un déplacement. Il possède :
  • une direction ;
  • un sens ;
  • une longueur, appelée norme.
ObjetExempleInterprétation
PointA(1 ; 2)Position dans le plan.
Vecteur→u = (3 ; -1)Déplacement de 3 vers la droite et 1 vers le bas.
Vecteur entre deux points→ABDéplacement de A vers B.

3. Coordonnées d’un vecteur

Si A(x_A ; y_A) et B(x_B ; y_B), alors :
→AB = (x_B − x_A ; y_B − y_A)
Soient A(2 ; 3) et B(7 ; 1). Calcule les coordonnées de →AB.
→AB = (x_B−x_A ; y_B−y_A)
→AB = (7−2 ; 1−3)
→AB = (5 ; -2)
Cela signifie qu’on va de A vers B en avançant de 5 horizontalement et en descendant de 2 verticalement.
Piège fréquent : →AB et →BA ne sont pas les mêmes vecteurs. Ils sont opposés.

4. Norme d’un vecteur

La norme d’un vecteur est sa longueur.
Si →u=(a ; b), alors :
||→u|| = √(a² + b²)
Calcule la norme du vecteur →u=(3 ; 4).
||→u|| = √(3²+4²)=√(9+16)=√25=5.
La norme du vecteur est 5.

5. Vecteurs égaux et vecteurs opposés

SituationConditionExemple
Vecteurs égauxMêmes coordonnées.(2 ; -1) = (2 ; -1)
Vecteurs opposésCoordonnées opposées.(2 ; -1) et (-2 ; 1)
Soient A(1 ; 2), B(4 ; 6), C(-2 ; 0) et D(1 ; 4). Les vecteurs →AB et →CD sont-ils égaux ?
→AB=(4−1 ; 6−2)=(3 ; 4).
→CD=(1−(-2) ; 4−0)=(3 ; 4).
Les deux vecteurs ont les mêmes coordonnées, donc ils sont égaux.

6. Addition de vecteurs

Pour additionner deux vecteurs, on additionne leurs composantes.
Si →u=(a ; b) et →v=(c ; d), alors :
→u + →v = (a+c ; b+d)
Calcule →u+→v avec →u=(3 ; -2) et →v=(5 ; 4).
→u+→v=(3+5 ; -2+4)=(8 ; 2).

Relation de Chasles

La relation de Chasles permet d’enchaîner des déplacements :
→AB + →BC = →AC
Si on va de A à B, puis de B à C, le déplacement total est-il →AC ?
Oui. C’est exactement la relation de Chasles : →AB+→BC=→AC.

7. Multiplication d’un vecteur par un réel

Multiplier un vecteur par un nombre réel change sa longueur et parfois son sens.
Si →u=(a ; b), alors :
k→u = (ka ; kb)
Valeur de kEffet
k>1vecteur plus long, même sens
0<k<1vecteur plus court, même sens
k<0sens opposé
k=0vecteur nul
Soit →u=(-2 ; 5). Calcule 3→u et -2→u.
3→u=(3×(-2) ; 3×5)=(-6 ; 15).
-2→u=(-2×(-2) ; -2×5)=(4 ; -10).

8. Colinéarité, alignement et parallélisme

Deux vecteurs sont colinéaires s’ils ont la même direction. L’un est un multiple de l’autre.
Si →u=(a ; b) et →v=(c ; d), alors ils sont colinéaires si :
a×d − b×c = 0
UtilisationIdée
Alignement de pointsA, B et C sont alignés si →AB et →AC sont colinéaires.
Parallélisme de droitesLes droites AB et CD sont parallèles si →AB et →CD sont colinéaires.
Les points A(1 ; 2), B(3 ; 6) et C(4 ; 8) sont-ils alignés ?
→AB=(3−1 ; 6−2)=(2 ; 4).
→AC=(4−1 ; 8−2)=(3 ; 6).
On vérifie la colinéarité : 2×6 − 4×3 = 12 − 12 = 0.
Les vecteurs sont colinéaires, donc les points A, B et C sont alignés.
Piège fréquent : des vecteurs peuvent être colinéaires sans être égaux. Par exemple (2;4) et (3;6) ont la même direction, mais pas la même longueur.

9. Translation d’un point

Une translation déplace tous les points selon un même vecteur.
Si A(x ; y) et →u=(a ; b), alors l’image A' de A par la translation de vecteur →u est :
A'(x+a ; y+b)
Le point A(2 ; -1) est translaté par le vecteur →u=(5 ; 3). Calcule les coordonnées de son image A'.
A'=(2+5 ; -1+3)=(7 ; 2).
L’image du point A est A'(7 ; 2).

10. Rotation d’un quart de tour autour de l’origine

Le document de l’UAA demande aussi de déterminer les coordonnées de l’image d’un point par une rotation d’un quart de tour autour de l’origine.
Rotation autour de OFormule
Quart de tour dans le sens trigonométrique, +90°(x ; y) → (-y ; x)
Quart de tour dans le sens horaire, -90°(x ; y) → (y ; -x)
Calcule l’image de A(3 ; 5) par une rotation d’un quart de tour dans le sens trigonométrique autour de l’origine.
Pour une rotation de +90° : (x ; y) → (-y ; x).
Donc A(3 ; 5) → A'(-5 ; 3).

11. Produit scalaire dans le plan

Le produit scalaire est un outil permettant notamment d’étudier les angles et la perpendicularité entre deux vecteurs.
Si →u=(a ; b) et →v=(c ; d), alors :
→u · →v = ac + bd
RésultatInterprétation
→u · →v = 0Les vecteurs sont perpendiculaires.
→u · →v > 0L’angle entre les vecteurs est aigu.
→u · →v < 0L’angle entre les vecteurs est obtus.
Les vecteurs →u=(2 ; 3) et →v=(6 ; -4) sont-ils perpendiculaires ?
→u · →v = 2×6 + 3×(-4) = 12 − 12 = 0.
Le produit scalaire est nul, donc les deux vecteurs sont perpendiculaires.
Remarque : le produit scalaire est utile, mais l’UAA insiste surtout sur les vecteurs dans le plan, leurs composantes, leurs opérations, l’alignement, le parallélisme, les translations et les rotations.

12. Droites dans le plan avec vecteurs

Une droite peut être décrite à l’aide d’un point et d’un vecteur directeur. Le vecteur directeur indique la direction de la droite.
Si une droite passe par A(x_A ; y_A) et a pour vecteur directeur →u=(a ; b), alors ses points peuvent s’écrire :
(x ; y) = (x_A ; y_A) + t(a ; b)
La droite d passe par A(1 ; 2) et a pour vecteur directeur →u=(3 ; 1). Donne trois points de la droite.
On utilise (x ; y)=(1 ; 2)+t(3 ; 1).
Pour t=0 : (1 ; 2).
Pour t=1 : (4 ; 3).
Pour t=2 : (7 ; 4).
Ces trois points appartiennent à la droite.

13. Applications pratiques

13.1 Vérifier un parallélisme

Soient A(0 ; 1), B(4 ; 3), C(2 ; -1) et D(10 ; 3). Les droites AB et CD sont-elles parallèles ?
→AB=(4−0 ; 3−1)=(4 ; 2).
→CD=(10−2 ; 3−(-1))=(8 ; 4).
On remarque que →CD=2→AB.
Les vecteurs sont colinéaires, donc les droites AB et CD sont parallèles.

13.2 Résultante de forces

Deux forces sont représentées par les vecteurs →F₁=(12 ; 5) et →F₂=(-4 ; 7). Calcule la force résultante.
La résultante est la somme des forces :
→R=→F₁+→F₂=(12−4 ; 5+7)=(8 ; 12).
La force résultante est →R=(8 ; 12).

15. Corrections détaillées

1. Un vecteur représente un déplacement avec direction, sens et norme. Les coordonnées d’un vecteur indiquent ses composantes horizontale et verticale. La norme est sa longueur. Deux vecteurs sont colinéaires s’ils ont la même direction. Deux vecteurs sont égaux s’ils ont les mêmes coordonnées.
2. Si A(x_A ; y_A) et B(x_B ; y_B), alors →AB=(x_B−x_A ; y_B−y_A).
3. Si →u=(a ; b), alors ||→u||=√(a²+b²).
4. Quart de tour +90° : (x ; y)→(-y ; x). Quart de tour -90° : (x ; y)→(y ; -x).
5. →AB=(8−2 ; 5−(-3))=(6 ; 8). Norme : √(6²+8²)=√100=10.
6. →u+→v=(1+5 ; 4−2)=(6 ; 2).
3→u=(3 ; 12) et 2→v=(10 ; -4).
3→u−2→v=(3−10 ; 12−(-4))=(-7 ; 16).
7. 6×3−9×2=18−18=0. Les vecteurs sont colinéaires. On peut aussi voir que (6 ; 9)=3(2 ; 3).
8. A'=(-2+4 ; 7−3)=(2 ; 4).
9. →AB=(3 ; 6) et →AC=(5 ; 10). Vérification : 3×10−6×5=30−30=0. Les vecteurs sont colinéaires, donc les points sont alignés.
10. →AB=(3 ; 6) et →CD=(3 ; 6). Les vecteurs sont égaux, donc les droites AB et CD sont parallèles.
11. →R=(10+3 ; -2+8)=(13 ; 6). Norme : ||→R||=√(13²+6²)=√205≈14,32.
12. Produit scalaire : 4×1+(-2)×2=4−4=0. Les vecteurs sont perpendiculaires.

18. Fiche mémo finale

Formules indispensables

  • →AB=(x_B−x_A ; y_B−y_A)
  • ||→u||=√(a²+b²) pour →u=(a ; b)
  • →u+→v=(a+c ; b+d)
  • k→u=(ka ; kb)
  • Colinéarité : a×d−b×c=0
  • Produit scalaire : →u·→v=ac+bd
  • Perpendicularité : →u·→v=0
  • Translation : (x ; y)→(x+a ; y+b)
  • Rotation +90° : (x ; y)→(-y ; x)
  • Rotation -90° : (x ; y)→(y ; -x)

Procédures

  1. Pour un vecteur entre deux points : arrivée moins départ.
  2. Pour une norme : racine de la somme des carrés.
  3. Pour aligner trois points : tester la colinéarité de deux vecteurs.
  4. Pour prouver un parallélisme : tester la colinéarité des vecteurs directeurs.
  5. Pour prouver une perpendicularité : calculer le produit scalaire.
  6. Pour une translation : ajouter les composantes du vecteur.
  7. Pour une rotation de quart de tour : appliquer la formule adaptée.

Pièges fréquents

  • Inverser →AB et →BA.
  • Confondre point et vecteur.
  • Oublier que la norme est toujours positive.
  • Dire que deux vecteurs colinéaires sont forcément égaux.
  • Se tromper de signe dans une rotation de +90° ou -90°.
  • Utiliser une formule de l’espace alors que cette UAA reste dans le plan.
