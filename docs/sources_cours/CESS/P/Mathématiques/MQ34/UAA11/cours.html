MQ34 UAA11 – Système d’équations linéaires
Cours complet imprimable – Jury CESS

Objectif : résoudre un problème de la vie courante qui se ramène à un système d’équations linéaires. Cette UAA couvre les systèmes de deux équations à deux inconnues, les systèmes de trois équations à trois inconnues, les méthodes de résolution, l’interprétation graphique et les problèmes contextualisés.
À l’examen : il faut savoir modéliser un problème, identifier les inconnues, traduire les informations en équations, choisir une méthode de résolution, vérifier la solution et remettre la réponse dans le contexte.

1. Repartir des bases : équation linéaire

Une équation linéaire est une équation où les inconnues sont au premier degré. Cela signifie qu’on ne trouve pas de x², xy, 1/x ou racine de l’inconnue.
ÉquationLinéaire ?Pourquoi ?
2x+3y=12Ouix et y sont au premier degré.
x²+y=5NonIl y a x².
3x−2y+z=8Ouix, y et z sont au premier degré.
xy=6NonLes inconnues sont multipliées.

2. Qu’est-ce qu’un système d’équations ?

Un système d’équations est un ensemble de plusieurs équations qui doivent être vraies en même temps.
Exemple de système 2x2 :
{ 2x + y = 11 ; x − y = 1 }

Résoudre le système, c’est trouver les valeurs des inconnues qui vérifient toutes les équations à la fois.

Piège fréquent : une valeur qui vérifie une seule équation ne suffit pas. Elle doit vérifier toutes les équations du système.

3. Système 2x2 : sens graphique

Un système de deux équations à deux inconnues représente généralement deux droites dans un plan. La solution est le point d’intersection des deux droites.
Situation graphiqueType de systèmeNombre de solutions
Deux droites qui se coupentSystème compatible déterminéUne solution unique
Deux droites parallèles distinctesSystème impossibleAucune solution
Deux droites confonduesSystème indéterminéUne infinité de solutions

4. Méthode 1 : substitution

La substitution consiste à isoler une inconnue dans une équation, puis à la remplacer dans l’autre équation.
Procédure :
1. Choisir une équation où une inconnue est facile à isoler.
2. Isoler cette inconnue.
3. Remplacer cette inconnue dans l’autre équation.
4. Résoudre l’équation obtenue à une inconnue.
5. Revenir à l’expression isolée pour trouver l’autre inconnue.
6. Vérifier dans les deux équations.
Résous par substitution :
{ x + y = 10 ; 2x + y = 14 }
Dans la première équation : x+y=10, donc y=10−x.
On remplace dans la deuxième :
2x+(10−x)=14
x+10=14
x=4
Puis y=10−4=6.
Solution : (x ; y)=(4 ; 6).
Vérification : 4+6=10 et 2×4+6=14.

5. Méthode 2 : combinaisons linéaires

La méthode des combinaisons linéaires, aussi appelée méthode d’élimination, consiste à additionner ou soustraire les équations pour faire disparaître une inconnue.
Procédure :
1. Aligner les inconnues et les nombres.
2. Multiplier éventuellement une ou deux équations pour obtenir des coefficients opposés.
3. Additionner les équations pour éliminer une inconnue.
4. Résoudre l’équation restante.
5. Remplacer pour trouver l’autre inconnue.
6. Vérifier.
Résous par combinaison :
{ 3x + 2y = 16 ; x − 2y = 4 }
On additionne les deux équations car +2y et −2y s’annulent :
(3x+2y)+(x−2y)=16+4
4x=20
x=5
On remplace dans x−2y=4 :
5−2y=4
−2y=−1
y=0,5
Solution : (5 ; 0,5).

7. Système impossible ou indéterminé

Système impossible

Un système est impossible s’il n’a aucune solution.
Résous :
{ 2x + 2y = 8 ; x + y = 7 }
La première équation équivaut à x+y=4.
La deuxième dit x+y=7.
Il est impossible que x+y vaille à la fois 4 et 7.
Le système est impossible : aucune solution.

Système indéterminé

Un système est indéterminé s’il possède une infinité de solutions.
Résous :
{ 2x + 2y = 8 ; x + y = 4 }
La première équation divisée par 2 donne x+y=4.
Les deux équations représentent donc la même droite.
Il y a une infinité de solutions : tous les couples qui vérifient x+y=4.

8. Systèmes 3x3

Un système 3x3 contient trois équations et trois inconnues, souvent notées x, y et z.
Exemple :
{ x+y+z=6 ; 2x−y+z=3 ; x+2y−z=2 }

La solution est un triplet (x ; y ; z) qui vérifie les trois équations.

9. Méthode de Gauss

La méthode de Gauss transforme progressivement le système pour obtenir une forme plus simple, souvent triangulaire.
Idée :
1. Garder une première équation comme pivot.
2. Utiliser cette équation pour éliminer une inconnue dans les autres équations.
3. Recommencer avec une deuxième équation pour éliminer une autre inconnue.
4. Obtenir une équation avec une seule inconnue.
5. Remonter pour calculer les autres inconnues.
Piège fréquent : dans la méthode de Gauss, le choix du pivot est important. Il faut privilégier un pivot simple, par exemple un coefficient 1 ou -1.

Exemple corrigé 3x3

Résous :
{ x + y + z = 6 ; x − y + z = 2 ; x + y − z = 4 }
On note les équations :
E1 : x+y+z=6
E2 : x−y+z=2
E3 : x+y−z=4

On soustrait E2 à E1 :
(x+y+z)−(x−y+z)=6−2
2y=4, donc y=2.

On soustrait E3 à E1 :
(x+y+z)−(x+y−z)=6−4
2z=2, donc z=1.

On remplace dans E1 :
x+2+1=6
x=3.

Solution : (x ; y ; z)=(3 ; 2 ; 1).
Vérification :
E1 : 3+2+1=6.
E2 : 3−2+1=2.
E3 : 3+2−1=4.

10. Modéliser un problème contextualisé

Procédure complète :
1. Lire l’énoncé lentement.
2. Repérer les informations numériques.
3. Choisir les inconnues et les définir clairement.
4. Traduire chaque phrase utile en équation.
5. Résoudre le système.
6. Vérifier mathématiquement.
7. Vérifier la plausibilité dans le contexte.
8. Répondre par une phrase.

Exemple boulangerie

Dans une boulangerie, Jacques achète 2 croissants et 1 pain au chocolat pour 2,80 €. Doris achète 1 croissant et 3 pains au chocolat pour 3,05 €. Quel est le prix d’un croissant et d’un pain au chocolat ?
On pose :
x = prix d’un croissant en euros.
y = prix d’un pain au chocolat en euros.

Traduction :
2x+y=2,80
x+3y=3,05

Depuis la première équation : y=2,80−2x.
On remplace dans la deuxième :
x+3(2,80−2x)=3,05
x+8,40−6x=3,05
−5x=−5,35
x=1,07.
Puis y=2,80−2×1,07=0,66.

Un croissant coûte 1,07 € et un pain au chocolat coûte 0,66 €.

Exemple pots de confiture

Sur une étagère, il y a 2 petits pots, 3 moyens et 1 grand. Le poids total est 5 kg. On sait qu’un grand pot pèse autant que 2 moyens, et qu’un moyen pèse autant que 2 petits. Quel est le poids de chaque type de pot ?
On pose :
p = poids d’un petit pot.
m = poids d’un pot moyen.
g = poids d’un grand pot.

Traduction :
2p+3m+g=5
g=2m
m=2p

On remplace m=2p et g=2m=4p dans la première équation :
2p+3(2p)+4p=5
2p+6p+4p=5
12p=5
p=5/12≈0,417 kg.
m=2p=10/12≈0,833 kg.
g=4p=20/12≈1,667 kg.

Un petit pot pèse environ 0,417 kg, un moyen 0,833 kg et un grand 1,667 kg.

13. Corrections détaillées

1. Un système est un ensemble d’équations à vérifier simultanément. Une inconnue est une valeur à trouver. Une solution vérifie toutes les équations. Un système impossible n’a aucune solution. Un système indéterminé a une infinité de solutions.
2. Dans un système 2x2, chaque équation peut représenter une droite. La solution est l’intersection. Deux droites parallèles donnent aucune solution. Deux droites confondues donnent une infinité de solutions.
3. La substitution est conseillée quand une inconnue est déjà isolée ou facile à isoler.
4. Les combinaisons linéaires sont conseillées quand les coefficients permettent d’éliminer facilement une inconnue.
5. x+y=9 et x−y=3. On additionne : 2x=12, donc x=6. Puis y=3.
6. On additionne les équations : 6x=24, donc x=4. Puis 2×4+3y=18, donc 3y=10, y=10/3.
7. La première équation divisée par 2 donne x+y=5. Les deux équations sont équivalentes. Le système est indéterminé : infinité de solutions.
8. E1 : x+y+z=10, E2 : x−y+z=4, E3 : x+y−z=2.
E1−E2 : 2y=6, donc y=3.
E1−E3 : 2z=8, donc z=4.
Dans E1 : x+3+4=10, donc x=3.
Solution : (3 ; 3 ; 4).
9. On pose c = prix d’un café, t = prix d’un thé.
Système : 2c+3t=10,40 et 4c+t=11,20.
Depuis la deuxième : t=11,20−4c.
Dans la première : 2c+3(11,20−4c)=10,40.
2c+33,60−12c=10,40, donc −10c=−23,20, c=2,32.
t=11,20−4×2,32=1,92.
Café : 2,32 €. Thé : 1,92 €.
10. On pose x = nombre de produits A et y = nombre de produits B.
Travail : 2x+y=40. Matière : x+3y=45.
Depuis y=40−2x.
Dans la deuxième : x+3(40−2x)=45.
x+120−6x=45, donc −5x=−75, x=15.
y=40−30=10.
On produit 15 unités de A et 10 unités de B.
11. m=2p et g=m+3=2p+3.
Dans p+m+g=18 : p+2p+(2p+3)=18.
5p+3=18, donc 5p=15, p=3.
m=6 et g=9.

15. Correction du mini-test

Q1. Depuis x−y=2, on a y=x−2. Dans 2x+y=13 : 2x+x−2=13, donc 3x=15, x=5. Puis y=3. Solution : (5 ; 3).
Q2. On additionne : (3x+2y)+(5x−2y)=19+13, donc 8x=32, x=4. Dans 3x+2y=19 : 12+2y=19, donc y=3,5. Solution : (4 ; 3,5).
Q3. La première équation divisée par 4 donne x+2y=5. Les deux équations sont identiques. Le système est indéterminé : il possède une infinité de solutions.
Q4. E1−E2 : 2y=6, donc y=3.
E1−E3 : 2z=8, donc z=4.
Dans E1 : x+3+4=12, donc x=5.
Solution : (5 ; 3 ; 4).
Q5. On pose c = prix d’un croissant et p = prix d’un pain au chocolat.
Système : 3c+2p=6,80 et 2c+4p=7,60.
On divise la deuxième par 2 : c+2p=3,80, donc c=3,80−2p.
Dans la première : 3(3,80−2p)+2p=6,80.
11,40−6p+2p=6,80, donc −4p=−4,60, p=1,15.
c=3,80−2×1,15=1,50.
Un croissant coûte 1,50 € et un pain au chocolat coûte 1,15 €.

16. Fiche mémo finale

Définitions

  • Système : plusieurs équations à vérifier en même temps.
  • Solution : couple ou triplet qui vérifie toutes les équations.
  • Système compatible déterminé : une seule solution.
  • Système impossible : aucune solution.
  • Système indéterminé : infinité de solutions.
  • Substitution : isoler une inconnue puis remplacer.
  • Combinaison linéaire : additionner ou soustraire pour éliminer une inconnue.
  • Méthode de Gauss : transformer un système pour le simplifier progressivement.

Procédure 2x2

  1. Choisir substitution ou combinaison.
  2. Éliminer une inconnue.
  3. Calculer la première inconnue.
  4. Remplacer pour trouver la deuxième.
  5. Vérifier dans les deux équations.

Procédure 3x3

  1. Choisir une équation pivot simple.
  2. Éliminer une inconnue dans deux équations.
  3. Obtenir un système 2x2.
  4. Résoudre le système 2x2.
  5. Remonter pour trouver la troisième inconnue.
  6. Vérifier les trois équations.

Procédure problème

  1. Définir clairement les inconnues.
  2. Traduire les phrases en équations.
  3. Résoudre.
  4. Vérifier la solution.
  5. Répondre dans le contexte avec les unités.

Pièges fréquents

  • Ne pas définir les inconnues.
  • Traduire une phrase dans le mauvais sens.
  • Oublier de vérifier la solution.
  • Confondre système impossible et indéterminé.
  • Faire une erreur de signe lors d’une combinaison.
  • Donner une réponse mathématique sans phrase de contexte.
